# Verity Works — brand identity

Everything here is generated by `make-brand.cjs` (kept with this folder). Re-running it produces
byte-identical files, so the identity is reproducible rather than a one-off export nobody can
recreate. Edit the generator, not the SVGs.

---

## The mark

A serif **V** with an amber dot at its shoulder.

The dot is a **footnote reference** — the typographic symbol for *"this traces to a source."*
That is the whole proposition: every claim Verity Works publishes points at evidence a customer
can check. The V is drawn with real thick/thin stroke contrast so it belongs to the same
typographic world as the site's Fraunces headings, rather than reading as a geometric tech glyph.

**Why it replaced the previous logo.** The old mark was a white checkmark on a green square. It
was off-palette (that green appears nowhere else in the brand, so the logo and the website looked
like two different companies), generic (a tick in a rounded square is the most common mark in
software), and — the reason that actually mattered — it said the opposite of the proposition. A
checkmark means *"approved, trust me."* It is the claim without the evidence, which is precisely
what this business exists to reject.

## Palette

Taken from the live site's `assets/base.css`, not invented, so the brand and the product are one
thing by construction.

| Token | Hex | Use |
|---|---|---|
| ground | `#0B0A08` | page and avatar background |
| surface | `#16140F` | panels, code blocks |
| ink | `#EFE7D3` | primary text, the mark on dark |
| ink-soft | `#A89C7E` | secondary text, captions |
| accent | `#C6A355` | rules, the mark on light |
| accent-bright | `#E4C878` | the citation dot, emphasis |
| ink-on-light | `#17150F` | the mark on a light ground |

Never introduce a colour outside this set. If something needs to stand out, use `accent-bright`
and use it once.

## Typography

| Role | Face | Notes |
|---|---|---|
| Headlines, wordmark | **Fraunces** 600 | the editorial voice; tight tracking (-0.5 to -1) |
| Body | **Inter** 400/600 | |
| Code, labels, taglines | **IBM Plex Mono** 400/500 | uppercase labels get 2.4–3 letter-spacing |

## Files

| File | Use |
|---|---|
| `mark-dark.svg` / `mark-light.svg` | the mark alone, transparent |
| `favicon.svg` | browser tab; rounded ground so it reads against any chrome |
| `avatar.svg` / `avatar-400.png` | profile picture, every platform |
| `lockup-dark/light/transparent.svg` | mark + wordmark + tagline |
| `banner-linkedin-1584x396.*` | LinkedIn cover |
| `banner-facebook-1640x856.*` | Facebook cover |

PNGs are provided because the platforms want raster uploads. The SVGs embed font *names*, not the
fonts themselves, so a machine without Fraunces installed will render the lockup text in a
fallback serif — **always upload the PNG where text is involved.**

## Checked, not assumed

- The avatar was rendered circle-cropped at 180, 110, 56 and 32px, because every platform crops it
  to a circle and the dot is what fails first. It survives to 32px.
- The favicon was rendered at 64, 32 and 16px. At 16px the dot nearly merges with the V's arm and
  the mark degrades to a clean V — acceptable, and the reason the dot was moved out and shrunk
  from the first draft.
- The Facebook banner is centred on the vertical midline, not the upper third, because Facebook
  crops hard top and bottom on mobile. The first draft lost the tagline on a phone.

## Tone of voice

Plain, specific, unhurried. State the method, not the adjective.

- **Say:** "Every example is extracted from a script that ran against the pinned version."
- **Not:** "We deliver world-class, guaranteed-quality documentation."

Never publish a guarantee, a superlative ranking, a customer count, a performance statistic or a
testimonial. Verity Works has no completed customers yet, and `lib/commercialGates.js` blocks all
five claim classes mechanically rather than relying on anyone remembering this paragraph.

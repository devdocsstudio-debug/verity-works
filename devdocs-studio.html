better-sqlite3 — Common Patterns Guide

const transfer = db.transaction((fromId, toId, amount) => {
  db.prepare('UPDATE users SET balance = balance - ? WHERE id = ?').run(amount, fromId);
  db.prepare('UPDATE users SET balance = balance + ? WHERE id = ?').run(amount, toId);
});

The gotcha most guides miss: the transaction only rolls back on a thrown JS error — an UPDATE matching zero rows doesn't throw.

pdf-lib — Quick Reference

const target = await PDFDocument.create();
const [copiedPage] = await target.copyPages(sourceDoc, [0]);
target.addPage(copiedPage);

The gotcha most guides miss: copyPages is called on the destination document, with the source as an argument.

jsonwebtoken — Algorithm-Confusion Check

// no `algorithms` option passed at all
jwt.verify(forgedHS256Token, rsaPublicKey);
// -> v9 infers the key is RSA and rejects it: "invalid algorithm"
//    (the classic RS256->HS256 attack is already mitigated by default --
//    but only while the key still parses as a real key)

The gotcha most guides miss: if the public key's PEM header/footer gets stripped (a real mistake — env vars and .env parsers do this), jsonwebtoken silently falls back to treating it as an HMAC secret and the attack works again. Pin { algorithms: ['RS256'] } explicitly to make the protection unconditional.
